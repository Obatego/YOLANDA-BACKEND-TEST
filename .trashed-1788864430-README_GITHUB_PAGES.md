# Yolanda Services — GitHub Pages deployment

## Important
Upload the **contents of this folder** to the root of the GitHub repository. Do **not** upload the ZIP file as `index.html`, and do not put the whole folder inside another folder.

The repository root must contain:
- `index.html`
- `login.html`
- `employee-profile.html`
- `dashboard.html`
- `yolanda.css`
- `assets/`
- `js/`
- `backend/`
- `.nojekyll`

The stylesheet is deliberately duplicated at `css/yolanda.css` for compatibility, but all pages now load the root `./yolanda.css` so GitHub Pages cannot lose the stylesheet because of a folder upload/path mismatch.

### GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

Then open the generated Pages URL. Hard-refresh once if an older cached page appears.
